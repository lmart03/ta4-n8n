¿SUNAT bloquea al robot? Otras formas de obtener los datos

Opción rápida: consultar por API

Obtiene los datos de la API de consultaderuc.pe, no de la Consulta Múltiple de SUNAT. El resultado queda marcado con esa fuente y no trae la fecha de inicio de actividades.

  1. 1 Descarga el archivo TXT con tus RUC. @if (inputUrl(); as url) { Descargar TXT }
  2. 2 En la Consulta Múltiple de SUNAT, usa «Validar mediante archivo», sube el TXT y descarga el ZIP que te devuelve. Abrir SUNAT
  3. 3 Sube aquí el ZIP; los resultados aparecerán en la tabla.
